# Citation and Evidence Standard

**Status:** Controlled standard

External scientific and technical claims cite primary literature, standards, official documentation, or authoritative datasets whenever possible. Repository Markdown uses author–date citations in prose—`(Author, year)`—linked to a stable entry in [the bibliography](../bibliography/references.md). Entries include authors, title, venue or publisher, year, edition or version when relevant, DOI or stable URL, and access date for mutable web sources.

Institutional claims cite the authoritative Bible chapter, ADR, RFC, experiment, incident, or implementation reference. Founder’s Editions are cited by book and PDF page during migration; Version 2 replaces those references with chapter anchors once canonical. A quotation preserves exact wording and location. Paraphrase is preferred when wording itself is not under analysis.

Evidence precedence is contextual: Constitutional Knowledge governs policy; external scientific sources govern general scientific claims; reproducible run artifacts govern Invariance experiments; operational records govern observed live behavior; code and tests govern current implementation behavior. Derived summaries never replace primary evidence.

Every empirical result records dataset identity and version, population and sample, interval, method, uncertainty, costs where relevant, code or producer version, and artifact location. Unsupported placeholder citations are forbidden.
