# System Acceptance and Evidence Matrix

**Status:** Controlled acceptance contract

**Observed scope, 2026-11-16:** Deployment and 377 targeted tests establish the
bounded recovery implementation, not system acceptance. R14/R15 supplied retained
rejections and deferrals with zero trials. Acceptance still requires changed
specifications passing independent review and genuine native execution/publication.
See [the recovery evidence record](../books/book-11-engineered-company-system/chapters/12-requirements-recovery-and-current-certification.md).

| Gate | Acceptance evidence | Failure meaning | Authority |
|---|---|---|---|
| Requirement coverage | Stable source-derived requirement ID, exact statement digest, owner, work package, verification, disposition and evidence rule | Capability is unplanned or its implementation claim is unsupported | Architecture owner and domain authority |
| Evidence identity | Stable source, edition, artifact, object, dataset, run, and decision identifiers with digests | Material cannot enter canonical memory | Knowledge steward |
| Retrieval fidelity | Versioned fixtures pass lexical, semantic, citation, contradiction, and protected-evidence cases | Research answers are non-authoritative | Knowledge steward and independent evaluator |
| Trial registration | Approved hypothesis and exact experiment digest precede a numbered trial | Run is exploratory/unregistered, never confirmatory | Research governance |
| Causal data | Availability timestamps, fit boundaries, resampling rules, and point-in-time fixtures pass | Result is invalid, not merely weak | Data steward and statistical reviewer |
| Laboratory truth | Accounting reconciliation, artifact schemas, run digest, cost/fill semantics, and repeated-run comparison pass | Run bundle cannot support a decision | Laboratory owner |
| Independent review | Statistical and adversarial reviewers differ from executor and each other | No institutional decision may be recorded | Governance service |
| Research decision | Decision binds exact result digest, rationale, reviewer evidence, and authority identity | Result remains evidence without promotion | Authorized research authority |
| Agent safety | Role package, capability, machine, risk, workflow, path, and lease checks pass | Task is released or stopped | Hermes control plane |
| External mutation | Separate scoped approval, target preflight, rollback, and postcondition evidence | Mutation remains prohibited | Human/operator authority |
| Shadow admission | Prospective data, immutable candidate, monitored drift, and incident controls pass | Candidate remains laboratory-only | Shadow admission authority |
| Demo/micro-live | Venue certification, reconciliation, kill switch, loss limits, and recovery drill pass | Capital path remains disabled | Production and risk authorities |
| Production | Portfolio admission, allocation, execution, observability, backup/restore, incident, and rollback gates all pass | No production promotion | Founder-designated committee |

Every gate produces a digest-bound evidence artifact. Dashboards, indexes, graphs, and summaries may display gate state but do not own it.
