# Agentic Systems Mastery Program

This directory turns the implemented Invariance Research system into a structured
technical apprenticeship. It is not a substitute for the constitutional books or the
as-built evidence in Book XI.

## Program documents

- [Program deliverables](PROGRAM_DELIVERABLES.md) — maps every requested phase to its
  artifact and remaining evidence boundary.
- [Knowledge map](knowledge-map.md) — what must be learned and where each concept
  appears in the real system.
- [Diagnostic assessment](diagnostic-assessment.md) — evidence-based starting
  exercises; generated code is not evidence of personal mastery.
- [Two-year learning roadmap](learning-roadmap.md) — twelve months of core mastery
  followed by a twelve-month advanced research trajectory.
- [Living systems laboratory](living-systems-laboratory.md) — the required learning
  cycle for substantial engineering work.
- [Learning journal](learning-journal.md) — durable reflection and design record.
- [Exercises](exercises/README.md) — progressive work against actual repositories.
- [Concept index](concepts/README.md) — theory mapped to implementation evidence.
- [Experiment registry](experiments/README.md) — proposed and completed mastery
  experiments.

## Evidence baseline

The program starts from the dated
[architectural reconnaissance](../architecture/ARCHITECTURAL_RECONNAISSANCE_2026-10-25.md)
and [architectural evaluation](../architecture/ARCHITECTURAL_EVALUATION_2026-10-25.md).
Later runtime changes do not retroactively alter those reports.

## Safety boundary

Exercises default to source inspection, unit tests, simulation, fixture data, and
paper/demo environments. No exercise grants permission to place a live order, inspect
unnecessary secrets, change production risk, or broaden an agent's authority.
