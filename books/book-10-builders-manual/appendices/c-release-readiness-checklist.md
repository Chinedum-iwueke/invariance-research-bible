# Appendix C — Release Readiness Checklist

Verify pinned code and dependencies; signed artifacts; configuration and schema compatibility; migrations and backups; environment and credentials; permissions; tests and security; capacity and quotas; telemetry and alerts; dashboards; runbooks; incident staffing; canary scope; risk and kill controls; rollback; downstream communication; evidence publication; owner approval; and expiry or review date.
