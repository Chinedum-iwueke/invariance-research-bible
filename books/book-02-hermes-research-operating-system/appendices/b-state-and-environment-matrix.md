# Appendix B — State and Environment Matrix

The four state dimensions remain independent.

| Dimension | Canonical values | Authority |
|---|---|---|
| Epistemic state | unknown, proposed, disputed, supported, weakened, rejected, retired | Research Intelligence evidence and belief records |
| Candidate maturity | registered, screened, replicated, robust, portfolio eligible, production eligible, degraded, quarantined, retired | Hermes governance transitions |
| Validation environment | backtest, robustness, shadow, execution replay, demo, micro-live, production | Laboratory or operational evidence record |
| Operational state | unavailable, ready, running, paused, degraded, halted, recovering, retired | Responsible service and Production control |

A transition record can cite one dimension while changing another. For example, failed demo authentication can move an operational component to degraded without weakening the predictive claim; adverse shadow evidence can weaken the claim and demote the candidate without implying that the shadow service failed.

Dashboards may display combined projections but must retain links to the four canonical records.
