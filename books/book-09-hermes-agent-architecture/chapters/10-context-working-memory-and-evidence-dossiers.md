# Chapter 10 — Context, Working Memory, and Evidence Dossiers

Context is a bounded task view assembled from instructions, state, retrieved evidence, and tool results. It is not the institutional memory itself.

## 10.1 Context assembly

Include task charter, authority, schemas, relevant state, evidence references, unresolved questions, and budgets. Rank sources by authority and recency while preserving contradictions.

## 10.2 Working memory

Plans, intermediate calculations, scratch hypotheses, and conversation summaries are ephemeral unless published as typed artifacts. Compaction preserves current task state, decisions, evidence, and blockers without promoting speculation.

## 10.3 Evidence dossier

For material work, assemble claims, sources, methods, artifacts, counterevidence, uncertainty, limitations, and decisions. Retrieval snippets do not substitute for primary sources.

## 10.4 Contamination

Untrusted retrieved text is labeled data. It cannot alter system policy or tool authorization. Protected evidence is segmented by access and exposure is logged.

> **Agent rule B9-AG10 — Context is a view, not authority**  
> Inclusion in a prompt does not change the provenance, truth status, access class, or permission effect of any item.
