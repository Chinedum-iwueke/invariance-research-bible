# Chapter 1 — Agents as Replaceable Institutional Workers

An agent is a bounded worker that interprets a task, uses authorized tools, produces typed artifacts, and reports evidence and uncertainty. It is not an organizational person, authority, or source of truth.

## 1.1 Separation

Identity, role, capability, model runtime, prompt version, tool grants, task authority, and accountable owner are separate objects. Changing the language model should not silently change permissions or institutional responsibility.

## 1.2 Replaceability

Agent work enters the institution through schemas, evidence references, deterministic services, and decisions made under Book II. Conversations are transient working material unless preserved as attributable artifacts.

## 1.3 Autonomy

Autonomy is freedom to choose tactics inside a charter. It does not include expanding scope, accessing protected data, approving one’s own work, allocating capital, mutating production, or hiding failed branches.

## 1.4 Failure

Agents can hallucinate, omit, loop, misuse tools, follow injected instructions, or become inconsistent across runs. Architecture limits consequence through least privilege, validation, budgets, review, and replayable state.

> **Agent rule B9-AG01 — Agents are workers, not authorities**  
> Institutional authority remains in governed roles and services even when an agent drafts, recommends, evaluates, or executes an authorized task.

## Source note

This chapter implements Books I–II’s distinction between cognition and authority. It makes no claim that conversational fluency implies reliability.
