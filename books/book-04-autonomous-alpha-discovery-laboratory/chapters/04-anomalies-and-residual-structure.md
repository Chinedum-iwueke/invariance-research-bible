# Chapter 4 — Anomalies and Residual Structure

Anomaly analysis examines deviations from explicit expectations and the structure left unexplained by current models. Residuals can reveal missing mechanisms, changing environments, measurement defects, or ordinary stochastic variation. Their existence does not prove opportunity.

## 4.1 Residual definition

A residual is defined relative to a model, target, representation, fit procedure, information set, and evaluation interval. The record states whether it is in-sample, cross-validated, out-of-sample, prospective, standardized, or transformed.

Residuals from a misspecified or leaking model inherit those defects. A pattern in residuals can arise because the baseline removed the wrong structure or used unavailable information.

## 4.2 Anomaly taxonomy

The laboratory distinguishes point, contextual, collective, relational, and operational anomalies. It also records whether the deviation concerns level, variance, tail, dependence, timing, liquidity, execution, cost, model error, or contract behavior.

Taxonomy supports retrieval and method choice. It does not establish distinct natural kinds; an event can belong to several views.

> **Discovery rule B4-DR04 — Diagnose before interpretation**  
> Every material anomaly investigation tests data, timestamp, universe, representation, implementation, benchmark, and selection explanations before assigning market or mechanism meaning.

## 4.3 Detection and calibration

Detection methods range from explicit rules and control charts to density, distance, predictive, change-point, and learned methods. Each detector declares reference population, score semantics, dependence assumptions, threshold policy, false-alert consequences, and calibration evidence.

A top-ranked score is relative to the candidate set. It is not a probability of scientific importance. Multiple detectors and repeated monitoring create selection that enters search history.

## 4.4 Persistence and transience

Persistence can support some mechanisms, but transient events can matter scientifically or operationally. The relevant question is whether duration, recurrence, and decay match the proposed process and decision horizon.

Monitoring after detection is prospective evidence. Retrospective window selection cannot be described as if the persistence rule was fixed beforehand.

## 4.5 From anomaly to question

An investigation assembles nearest prior events, artifact tests, effect magnitude, uncertainty, possible mechanisms, alternatives, required data, and decision relevance. It can dismiss the anomaly, monitor it, create an engineering defect, register a scientific question, or trigger authorized containment.

Only a scoped question proceeds to hypothesis formation. The anomaly record remains linked so later work can see how attention was selected.

## 4.6 Negative anomaly findings

Diagnosing a timestamp error, survivorship bias, stale price, or expected tail event is a valid discovery outcome. It improves detectors and prevents false opportunity claims. If the investigation itself is invalid, the distinction is recorded.
