# Chapter 13 — Experiment, Trial, and Decision Lineage

Scientific memory must connect a decision to the evidence and adaptive search that produced it. A performance table without its hypothesis, data, representation, code, trial family, review, and later operation cannot support reliable comparison or learning.

## 13.1 The lineage chain

The canonical chain links:

source or observation → dataset → representation → question → hypothesis → trial registration → experiment specification → run → primary artifact → analysis → evidence bundle → independent review → dossier → decision → release or deployment → operational outcome → belief or policy update.

Not every episode uses every object, but missing links are explicit. Each relationship identifies versions, time, producer, and applicable authority.

## 13.2 Laboratory memory

Bulletproof BT publishes primary run bundles under a versioned producer contract. Research Intelligence ingests their identities, schemas, manifests, diagnostics, artifacts, and relationships. It can calculate derived comparisons, but those identify the derivation and never replace producer artifacts.

The exact current Book V fields remain unclaimed until its repository audit. Book III requires invariant semantics: stable run identity, reproducible inputs, code and environment identity, temporal policy, outputs, validation disposition, and lineage.

> **Knowledge rule B3-KR13 — Primary producer authority**  
> Experiment memory preserves the authoritative producer artifact and schema version; screenshots, prose summaries, and reconstructed tables remain derived evidence.

## 13.3 Trial and search lineage

Trial Registry events link hypothesis creation, specification variants, parameter search, result views, selection, amendments, and protected-evidence exposure. Research Intelligence supports semantic family detection and nearest-prior retrieval. Hermes retains registry and access authority.

Related-trial counts do not determine statistical correction. The evidence record preserves the selection process and dependency information required for Book IV’s methods.

## 13.4 Decision lineage

A decision links the exact dossier, policy, candidate or object version, participants, dissent, conditions, expiry, and authorized transition. Later outcomes link back without rewriting the decision-time state.

Impact traversal works in both directions. A reviewer can ask which sources and runs supported a production decision or which decisions depend on an invalidated dataset, representation, method, or artifact.

## 13.5 Reproduction and supersession

A reproduced result is a new run linked to the earlier specification and environment, not a replacement. A replication uses new data aimed at the same scientific question and records material design differences.

Supersession preserves why a newer object became preferred. Retirement and lawful deletion retain permitted tombstones so the chain can explain a gap without exposing prohibited content.

## 13.6 Lineage quality

Completeness, identity resolution, schema compatibility, temporal consistency, and dependency cycles are tested. A fully connected graph can still be wrong; lineage quality includes sampled replay against primary artifacts and downstream decision checks.

Lineage succeeds when institutional claims can be traced to their actual evidence and consequences—not when a diagram contains many edges.
