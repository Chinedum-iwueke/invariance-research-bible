# Chapter 12 — Episodic, Semantic, Procedural, Working, and Reflective Memory

Knowledge classes describe where content comes from and what authority it carries. Memory forms describe how the institution uses content in cognition. Research Intelligence implements six functional forms over the same canonical evidence core rather than six isolated stores.

## 12.1 Semantic memory

Semantic memory holds concepts, definitions, claims, sources, mathematics, methods, variables, and established relationships. It supports explanation, comparison, and retrieval across episodes. Authority and provenance remain attached; a frequently retrieved claim does not become true through use.

## 12.2 Episodic memory

Episodic memory preserves research sessions, experiments, reviews, decisions, deployments, incidents, and observed outcomes. A research episode records the question, prior position, dossier, alternatives, methods, assumptions, work, surprise, decision, lesson, and new questions.

Rationale captured at decision time is distinguished from retrospective explanation. Both can be useful, but hindsight cannot be presented as contemporaneous belief.

## 12.3 Procedural memory

Procedural memory contains standards, policies, methods, APIs, playbooks, runbooks, and practiced controls. Procedures identify effective version, owner, prerequisites, exceptions, and evidence of exercise.

Documentation of a procedure does not prove operational readiness. Tests, drills, and observed use supply separate evidence.

## 12.4 Working memory

Working memory is the bounded context of an active task: charter, selected evidence, intermediate artifacts, unresolved issues, and tool state. It is temporary, permission-scoped, and minimized. Material outputs are published to durable memory at closeout; irrelevant or protected context expires under policy.

Working memory is not a model’s context window. A model may receive a derived context view while the task record remains external and recoverable.

## 12.5 Executive cognition

Executive cognition supports attention, priorities, schedules, resource constraints, dependencies, and authority. It consumes evidence about programs and unresolved questions but does not transform uncertain value estimates into objective rankings.

Hermes owns allocation and decision authority. Research Intelligence supplies the evidence and memory needed to exercise it.

## 12.6 Reflective memory

Reflective memory contains postmortems, contradictions, calibration, recurring failure patterns, meta-method evidence, and proposals for institutional improvement. It compares expectation with outcome and links lessons to adopted changes or justified non-change.

Reflection does not acquire constitutional authority. Proposed policy or doctrine changes follow governance.

> **Knowledge rule B3-KR12 — Memory forms share evidence**  
> Semantic, episodic, procedural, working, executive, and reflective memory are functional views over common identities and lineage; they may not create competing versions of institutional truth.

## 12.7 Consolidation and forgetting

Episodes can update semantic beliefs, procedures, or reflective patterns through attributable review. Consolidation preserves the evidence chain and does not generalize beyond supported scope.

Forgetting includes expiry, retirement, access revocation, deduplication, and lawful deletion. It changes retrieval status while preserving permitted lineage. The objective is useful, governed continuity—not maximal retention.
