# Appendix B — Reproducibility and Truth Checklist

Before interpretation, confirm the code pin and dependency environment; immutable dataset manifest; canonical resolved configuration; strategy, hypothesis, representation, estimator, and schema versions; seeds and concurrency policy; UTC and source-time validity; completed-bucket resampling; fit and transform separation; instrument and cost rules; order-to-fill and fill-to-position reconciliation; gross-to-net and cash-to-equity identities; required artifact presence and parsing; truth-validation status; experiment manifest completeness; protected-evidence exposure; and retry lineage.

Reproduce a representative run in a new output path. Normalize only registered operational fields. Compare decisions, fills, trades, equity, performance, and artifact digests. Record command, environment, counts, skips, failures, runtime, and deviations.

A favorable metric never waives a failed checklist item.
