# Appendix A — Run Bundle Contract

A finalized run bundle records run and attempt identities; hypothesis, experiment, code, environment, data, representation, estimator, configuration, and seed identities; temporal and evidence policies; artifact manifest; schema identities; content digests; validation disposition; and known limitations.

The classic minimum evidence set is resolved configuration, decisions, fills, equity, trades, performance, bucket performance, and run status. A target bundle also preserves order lifecycle, data scope, source-time coverage, environment lock, audit and reconciliation reports, and a final integrity manifest. Conditional artifacts state their enabling condition. Missing required artifacts invalidate the bundle.

Operational fields such as creation timestamp and storage locator are excluded from scientific run identity but retained for custody. Derived reports append lineage; they never rewrite primary artifacts.
