# The Invariance Research Bible

The Invariance Research Bible is the constitutional and technical corpus of Invariance Research, a scientific institution that happens to trade. The series defines how the institution reasons, operates, discovers, experiments, learns, allocates, executes, organizes agents, and builds its systems. It improves the discipline and reproducibility of research; it does not guarantee profitable alpha.

## Canonical series

1. [The Invariance Doctrine](books/book-01-invariance-doctrine/README.md) — why the institution exists.
2. [The Hermes Research Operating System](books/book-02-hermes-research-operating-system/README.md) — how the institution operates.
3. [Research Intelligence](books/book-03-research-intelligence/README.md) — how it thinks and remembers.
4. [The Autonomous Alpha Discovery Laboratory](books/book-04-autonomous-alpha-discovery-laboratory/README.md) — how it discovers.
5. [Bulletproof BT Laboratory](books/book-05-bulletproof-bt-laboratory/README.md) — how it experiments.
6. [Machine Learning for Scientific Discovery](books/book-06-machine-learning-for-scientific-discovery/README.md) — how it learns.
7. [Capital Allocation, Portfolio Construction & Risk Engineering](books/book-07-capital-allocation-portfolio-construction-risk-engineering/README.md) — how it survives and allocates.
8. [Market Microstructure & Execution Science](books/book-08-market-microstructure-execution-science/README.md) — how it executes.
9. [Hermes Agent Architecture](books/book-09-hermes-agent-architecture/README.md) — who performs the work.
10. [The Builder's Manual](books/book-10-builders-manual/README.md) — how to build the institution.

The narrative dependency is **why → operate → think → discover → experiment → learn → allocate → execute → staff → build**.
