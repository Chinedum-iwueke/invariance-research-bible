## Root-cause record

The unconstrained collection command traversed large generated research trees because
pytest had no `testpaths`. Explicit test collection then exposed a missing declared
dependency, a Python 3.11 dataclass fixture error, deleted YAML contracts for strategies
that still existed, assertions frozen before later preregistered grid changes, legacy
data-path assumptions, an alert durability defect, operational identifiers inside
semantic determinism comparisons and an unbounded pandas major-version upgrade.

The seven historical Appendix E failures were reproduced before repair. Fixes restore
contracts from repository history, bind the supported environment, retain both legacy
and market-namespaced data readers, and update tests only where Git history proves the
contract intentionally changed. No test was skipped, xfailed or deleted to obtain
closure, and no strategy or alternate engine was introduced.
