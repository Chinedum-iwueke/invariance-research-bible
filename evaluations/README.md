# Agentic Systems Evaluations

This directory defines how Invariance Research evaluates its software architecture and
agentic workflows. It deliberately separates:

1. platform reliability and verified task completion;
2. research evidence quality and scientific validity; and
3. trading execution correctness and authority.

Backtest profitability is not a proxy for any of the three.

## Documents

- [Advanced orchestration research](advanced-orchestration-research.md)
- [Reliability and evidence metrics](reliability-metrics.md)
- [Comparative benchmark design](benchmark-design.md)
- [Experiment result format](experiment-results/README.md)

All comparisons must bind model, prompt, tool access, data, execution budget, and
environment sufficiently to distinguish an architecture effect from a confounder.
